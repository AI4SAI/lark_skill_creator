# SAI

从用户要完成的事情出发。先读对应的一份资料，需要时再沿链接展开，不必通读整个手册。

| 用户要做什么 | 读哪份资料 |
| --- | --- |
| 了解 SAI，选择控制台、终端、Pilot 或社区 | [平台入口](references/platform.md) |
| 注册、登录、默认工作身份、开通站点、SSH 或挂载文件 | [账号与连接](references/access.md) |
| 管理组织、选择项目、邀请同事或外部合作者 | [团队协作](references/collaboration.md) |

| 使用科学软件、环境和模板，排查性能 | [软件与性能](references/software.md) |

查询当前价格、站点资源、权限、额度、余额和任务状态时，使用当前可用工具返回的事实。手册中的金额、分区和配额示例不代表用户此刻的条件。无法查询时说明缺口，不猜数。

操作沿用用户选择的站点、目录、计算账户和任务。文件访问权、计算权、付款权与对话访问权分别判断；切换目录不会自动改变其余权限。执行用户已经授权的操作，遇到新的费用、分享范围或目标歧义时再澄清。

回答先给结论和下一步。需要依据时给原文链接、实际状态或账单；保留手册作者的例子和表达，不把整篇教程重写成长篇说明。
