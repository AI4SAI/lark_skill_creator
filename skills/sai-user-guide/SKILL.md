# SAI

按用户要做的事，先读对应的一份资料，需要更多细节时再沿链接展开。

| 用户要做什么 | 读哪份资料 |
| --- | --- |
| 了解 SAI，选择控制台、终端、Pilot 或社区 | [平台入口](references/platform.md) |
| 注册、登录、默认工作身份、开通站点、SSH 或挂载文件 | [账号与连接](references/access.md) |
| 管理组织、选择项目、邀请同事或外部合作者 | [团队协作](references/collaboration.md) |
| 选择目录、共享数据、分配存储额度、处理空间不足 | [存储与数据](references/storage.md) |
| Slurm 账户推定、任务提交、暂停／suspend、取消与计费误解 | [计算任务](references/compute.md) |
| 使用科学软件、环境和模板，排查性能 | [软件与性能](references/software.md) |
| 用自然语言开展科研、管理 Agent 工作和计算 | [SAI Pilot](references/pilot.md) |
| 查经验、提问、回答、分享成果，向社区求助 | [SAI BBS](references/community.md) |
| 选择按量、随心算或合同组合，查费用、Credit 和激励 | [费用与服务](references/billing.md) |
| 让当前 Agent 实际操作 SAI | [工具使用](references/tools.md) |

价格、站点资源、权限、额度、余额和任务状态通过可用工具查询。手册中的示例用于说明规则。查询失败时说明哪些信息尚未取得。

操作沿用用户选择的站点、目录、计算账户和任务。分别核对文件、计算、付款和对话访问权限。已有授权内的操作继续执行，遇到新的费用、分享范围或目标歧义时再澄清。

回答先给结论和下一步，需要依据时附原文链接、状态或账单。保留手册作者的例子和表达。

查具体操作、示例或 QA 时，按需读取[手册原文](references/handbook/index.md)。
