# SAI Pilot · 赛先生领航员

[Pilot](https://pilot.open-sai.com/)是连接真实科研文件和计算资源的 Agent 工作台。可以让它读代码、改脚本、处理数据、准备计算、查看日志和整理结果，也可使用终端、Git、项目环境、Skills 和多 Agent 协作。可用工具和资格在工作台查看。

例如：“检查这个 ABACUS 输入，先给我运行方案和费用估计。”先选对工作目录，检查输入和模板，再决定运行规模、计算账户及预算。只有确认或已有预授权覆盖的计算才提交。提交后从任务记录查看排队、运行状态、失败原因和产物。

文件所在目录、计算归属和付款来源分别确认。使用另一个项目的计算资源需要该项目的计算授权，对话访问也需单独授权。团队分享对话时，使用工作台的对话协作入口并确认分享范围。

SAI 模型调用和托管计算按各自当前工作目录确定费用账户。换目录影响后续请求，已确认的计算方案、任务和旧费用保留原账户。

AI 服务设置的金额是自动补足的预留目标，累计消费可以超过它。未用预留占本账户资金，停用并确认回收后释放，已发生费用照常结算。见[费用 QA](handbook/b0585e709557547e77b329b0/index.md)。

已有工作优先回到原对话继续。个人 Codex 可以继续使用 SAI CLI。在 Pilot 的“设置 → 导入 Agent 资料”中，可以选择导入已有记忆、Skills 和会话。“设置 → SAI 使用指引”提供给命令行 Agent 安装 SAI Skill 的入口。

自带 API Key、委派 Codex／Claude Code、多个主会话协作和网页终端续接，见作者的 [Pilot 专项问答](handbook/048acb9654a77da0594d4cac/index.md)。

遇到需要同行经验的问题，可从原任务检索[BBS](community.md)，挑选适合公开的内容准备提问。工作台提供社区确认入口时，由作者确认提交。没有该入口时，提供草稿和 BBS 链接。发帖后结合帖子和回复继续原科研任务。
