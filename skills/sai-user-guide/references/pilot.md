# SAI Pilot · 赛先生领航员

[Pilot](https://pilot.open-sai.com/)是连接真实科研文件和计算资源的 Agent 工作台。可以让它读代码、改脚本、处理数据、准备计算、查看日志和整理结果；需要时仍可使用终端、Git、项目环境、Skills 和多 Agent 协作。具体可用工具和资格看当前工作台。

例如：“检查这个 ABACUS 输入，先给我运行方案和费用估计。”先选对工作目录，检查输入和模板，再决定运行规模、计算账户及预算。只有确认或已有预授权覆盖的计算才提交。之后沿真实任务查看排队、运行、失败原因和产物，不能把 Agent 说“完成了”当成任务完成凭据。

文件所在目录、计算归属和付款来源分别确认。切换目录不会自动取得另一个项目的计算权；能读共享文件，也不代表能读同事的对话。团队需要共享对话时使用实际提供的对话协作入口，单独确认分享范围。

已有工作优先回到原对话继续。长任务、多 Agent 和跨任务协作使用当前宿主提供的能力，不另建一套聊天记录或后台监听。个人 Codex 可以继续使用 SAI CLI；不要声称 Pilot 已自动同步其历史、记忆或私人 Skills。

遇到需要同行经验的问题，可从原任务检索[BBS](community.md)，挑选适合公开的内容准备提问。若工作台提供社区确认入口，由作者确认提交；否则提供草稿和 BBS 链接。后续依据真实帖子与回复继续原科研任务。
