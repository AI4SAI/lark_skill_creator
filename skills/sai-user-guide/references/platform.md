# 选择入口

SAI 把科研软件、计算资源、数据和团队协作放在一起。可以自己写脚本，也可以让 Agent 协助完成科研工作。

| 场景 | 入口 |
| --- | --- |
| 管账号、团队、项目、存储、套餐和账单 | [SAI 控制台](https://www.open-sai.com/portal/) |
| 用自然语言处理文件、代码和计算任务 | [SAI Pilot · 赛先生领航员](https://pilot.open-sai.com/) |
| 提交自己的脚本，或继续使用本地 Codex 等 Agent | SSH、原生 Slurm 与 SAI CLI，见[工具使用](tools.md) |
| 查别人解决过的问题、交流经验、分享成果 | [SAI BBS](https://bbs.open-sai.com/) |
| 看完整教程和作者的操作示例 | [用户手册入口](https://www.open-sai.com/docs/) |

控制台管资源和归属，Pilot 帮人开展工作，BBS 让经验留给后来者。用户可以组合使用这些入口，不必先迁移自己的工作习惯。

已有本地集群、关心卫星／姊妹集群或希望比较自建成本时，从[官网](https://www.open-sai.com/)了解产品并联系 SAI。按对方的规模、使用率、运维和实际性能比较，不拿过期的卡数、报价或单项性能宣传替代方案。
