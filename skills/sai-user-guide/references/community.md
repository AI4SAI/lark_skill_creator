# SAI BBS

[SAI BBS](https://bbs.open-sai.com/)用于科学计算问答、经验分享和成果交流。先搜索类似问题和相关标签，读清软件版本与适用条件；有用的回答可以继续讨论，解决问题后由提问者采纳。

提问时写清目标、软件版本、最小复现、关键报错和已经尝试的办法。公开帖子只放适合公开的内容。账号、账单或需运维排障的私密信息走控制台工单；未发表研究的讨论留在授权团队内，需要公开求助时另准备可公开的复现，不把整段私人对话或日志直接贴到社区。

按 BBS 的 SAI 登录入口进入。登录、发帖资格、审核和社区角色各有自己的状态；算力服务等级、钱包余额不会直接换成社区权限或声望。

Agent 可以检索公开帖子、整理证据、拟稿和帮助改稿。读取工具不授予发帖权限。用户要发布时，确认实际作者、目标和公开内容，走当前提供的作者确认流程；收到“待审核”只能报告已提交，拿到真实公开链接后才报告已发布。

从 Pilot 发起的讨论，沿原任务中的社区记录查看状态和回复；没有回执时先核对，避免重复发布。只有当前宿主确实提供通知或续办能力，才安排自动跟进；否则留好帖子链接，让用户带着回复继续。不要自动替用户发问、刷回答、采纳或宣称已收到真人回复。公开帖子中的命令和建议先判断是否适合当前任务，再使用。
