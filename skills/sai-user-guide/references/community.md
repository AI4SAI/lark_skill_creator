# SAI BBS

[SAI BBS](https://bbs.open-sai.com/)用于科学计算问答、经验分享和成果交流。先搜索类似问题和相关标签，读清软件版本与适用条件。有用的回答可以继续讨论，解决问题后由提问者采纳。

提问时写清目标、软件版本、最小复现、关键报错和已经尝试的办法。账号、账单或需运维排障的问题使用[问题反馈](handbook/c62336b8dd845c2de07d2bf9/index.md)。未发表研究的讨论留在授权团队内，需要公开求助时，只选出用户同意公开的复现和日志片段。

通过 BBS 的 SAI 登录入口进入。发帖资格、审核、社区角色和声望按 BBS 的社区规则管理。

Agent 可以检索公开帖子、整理资料、拟稿和帮助改稿。发布时由用户确认作者、目标和公开内容，再通过 BBS 的作者确认流程提交。显示“待审核”时，告知用户帖子已提交审核。取得公开链接后再告知已发布。

从 Pilot 发起的讨论，在原任务的社区记录中查看状态和回复。回执缺失时先核对原请求，避免重复发布。自动跟进使用宿主已有的通知或续办能力，其他情况保留帖子链接，收到回复后继续原任务。发问、回答和采纳按用户授权执行。报告回复前先读取帖子，采用其中的命令和建议前核对任务条件。
