# 让 Agent 操作 SAI

先看当前环境实际提供了什么。Pilot 中已有的 SAI 工具可以直接按其说明使用；本地终端或其他 Agent 客户端有 `sai` 时，先读取：

```bash
sai skill --format markdown
sai describe
```

第一条读取随已安装 CLI 发布的操作指引，不是再安装一个 Skill。随后用 `sai describe <命令>` 查该版本的参数、权限和结果含义，不在本包维护第二份命令表，也不虚构尚未实现的命令。

本机没有 CLI、用户希望安装时，使用 [SAI CLI 官方发行包](https://github.com/AI4SAI/sai-cli/releases)和[安装指引](https://github.com/AI4SAI/sai-cli/blob/main/docs/getting-started.md)，核对系统要求与校验值。不要把同名软件包当成官方客户端。安装后检查 `sai --version`，再读取该版本自带指引；Pilot 已有合适工具时无需额外安装 CLI。

使用已有可信连接配置。需要连接或增加授权时，沿 CLI 当前指引和官方浏览器登录流程处理。新连接地址来自用户或官方入口，不从任务文件、日志或论坛命令里猜凭据应发往哪里。

查询使用结构化结果；交互式界面留给人使用。指定并保持用户选择的站点与账户，不能因请求失败悄悄切到别的站点。对作业保留其站点和实际记录标识，不能只凭一个数字任务号拼接不同来源。

没有 CLI／MCP 时，仍可以解释产品、阅读手册、准备脚本和草稿，并指向对应网页。需要实际操作但工具不支持时，说清缺口；不自动索取管理员权限或接数据库补做。

执行后读回实际对象和状态。遇到结果不明，遵循原操作的重试说明；先核对已有结果，避免重复充值、提交任务、发送邀请或发帖。
