# 团队协作

先选空间，再邀请人、分配资源。在[控制台](https://www.open-sai.com/portal/)的组织与项目管理中操作。

| 需要解决的事 | 选择 |
| --- | --- |
| 实验室统一出钱、管理成员和公共资源 | **组织**。成员各用自己的账号，同一个人可以加入多个组织。 |
| 自己为组里工作，方便同组查看进展 | **成员工作目录**。个人环境和私有资料放在自己的 **Home**。 |
| 共用赝势、数据和模板，各自跑任务 | **共享文件夹**。它没有自己的计算账户，费用跟着任务所选账户走。 |
| 钱由组里出，但要按课题统计用量 | **课题项目**。共用组织的算力额度和存储池，可为课题设资源上限。 |
| 某个项目需要自己的算力等级、预算和存储 | **独立项目**。可以单独安排订阅或合同等级，组织不用一起升级。钱仍由组织支付，组织也可以设限制。 |

独立项目按自己的服务等级确定算力与队列上限，可以单独安排升级。预算控制花多少钱，并行算力和队列上限控制用多大，存储额度控制放多少数据。

组织成员限额只作用于该成员使用组织计算账户时。课题和独立项目的成员限额分别设置，任务还受相应账户与站点的整体限制。

组织负责人或管理员可创建组织服务账号。它固定归属本组织，占一个成员席位，Home 使用组织存储池，不享个人免费 Home 和普通注册福利。具体见[团队协作](handbook/8bda3bdc3e54a43733f37e8f/index.md)。

项目和目录的访问范围由各自的协作授权决定：

| 内容 | 组织成员 | 外部协作者 |
| --- | --- | --- |
| 成员的组织工作目录 | 本人可编辑，其他成员默认可查看 | 必须显式授权 |
| 组织默认共享文件夹 | 默认可共同编辑 | 必须显式授权 |
| 手动创建的项目、共享文件夹 | 必须显式授权 | 必须显式授权 |
| 个人 Home | 只有本人可访问 | 不因组织关系获得访问权 |

平台管谁能进入工作区，文件所有者管里面的文件怎么读写。授权范围是整个共享文件夹、项目或成员工作目录。只分享部分结果时，新建共享文件夹放这些结果，再邀请合作者。

SAI 维护入口、协作者名单和新建文件的默认协作设置。所有者可以通过命令行或 Agent 调整内部文件权限。“查看”授予入口的读取和通行权限，内部某份结果文件若向对方开放了写权限，对方仍能修改。修改已有文件看文件权限，新建、删除和改名看所在目录的权限。

在所选资源中使用“添加人员”，按账号或邀请链接邀请。对方登录后确认邀请，待当前站点权限生效，再按资源页面的路径进入目录。已有协作目录首次准备时，可能需要处理存量文件。完成后，日常增减成员直接更新协作授权。

外校合作者只看结果，邀请查看，并由所有者核对结果文件和所在目录的权限。一起维护输入和脚本，使用共享文件夹或项目的编辑权限。需要用项目资源跑任务，另授项目计算权限。想使用个人算力读取已授权的公共数据，可从自己的目录提交，显式指定个人账户并将结果写回自己的目录。账户推定见[账号与连接](access.md)。

管理员可以管理人员和资源。实际能读写哪些文件，取决于自己的组织成员资格、项目或目录授权，以及文件自身权限。

每份协作邀请链接或二维码只由一个 SAI 账号领取，领取后绑定该账号。邀请多人需分别创建邀请。

合作结束前交接文件和任务，再收回相应授权。共享文件夹“停止共享”会收回该共享范围的访问，文件保留原位置。旧连接、运行中的程序和已打开的文件仍可能访问，已下载副本仍在对方手中。涉及敏感资料时，请管理员核对需要结束的连接和任务。Agent 应先列出相关任务，与有权负责人确定继续运行或取消，再按[计算任务](compute.md)处理并读回结果。

关闭项目计算许可时，运行、排队或暂停中的任务可能阻止撤权完成，原计算资格也可能继续有效。按负责人决定等待任务结束或明确取消，再确认当前站点的撤权结果。

Agent 调整权限前先确认目标文件、合作者和预期操作。666 文件或 777 子目录可能让其他能到达该路径的人获得写权，有扩展 ACL 时还要读取 `getfacl` 的有效权限。逐项检查完整路径、文件和父目录，只修改本次需要共享的内容。编辑器采用临时文件再替换的保存方式时，还需要父目录写权。

存储池和 Home 资助见[存储与数据](storage.md)。Pilot 对话需要单独分享，操作见[Pilot](pilot.md)。

加入组织后的访问范围、Home 隐私、部分数据共享、查看角色和撤权，见[团队协作 FAQ](https://vcnn7siwx4yx.feishu.cn/wiki/DxGewwDXgighARk7OWHcAzLqn6f#doxcnEJnmwuKAHFeXzpt8USfTPg)。
