# 账号申请

> SAI 已采用个人账号与组织、项目分离的管理方式。每位用户只注册一个 SAI 账号，之后可在同一账号内加入多个组织或项目。旧飞书申请表不再作为日常注册主入口。

[进入 SAI 控制台，开始注册](https://open-sai.com/portal/)

## 申请前请确认

- 自助注册面向年满 18 周岁、具有完全民事行为能力的用户。未成年人确有科研、教学或竞赛需求，请由监护人和所属机构联系 SAI 安排。
- 准备一个由本人控制、能够正常收信的常用邮箱。后续可能需要按页面提示完成身份认证。
- 一个自然人只保留一个账号。已有账号的用户应选择登录或绑定已有账号，不要再次注册。

## 申请步骤

1.  **验证身份：**在 SAI 登录页选择邮箱验证码或页面提供的第三方账号。首次使用且尚未绑定 SAI 账号时，选择“注册新账号”。
2.  **补全基础资料：**验证常用邮箱，填写昵称，分别阅读并确认《SAI 平台服务与社区协议》和《SAI 隐私政策》。
3.  **完成 SAI 通行证：**确认用于 SSH 登录和提交作业的用户名，保存页面要求的资料。昵称和 SSH 用户名用途不同。
4.  **完成身份认证：**选择页面实际提供的认证方式，阅读相应说明后提交。需要处理敏感个人信息时，页面会另行征得同意。
5.  **等待开通：**认证完成后，SAI 会继续开通计算账号和获准站点。开通状态、站点访问、登录密钥和后续操作以 SAI 通行证中的提示为准。

## 组织、项目与计费

个人账号开通后，可通过邀请或申请加入实验室、企业组织或独立项目。组织和项目管理员在授权范围内管理成员、资源和计费账户；加入新团队不需要重新注册账号。提交作业或购买服务前，请确认当前身份、站点和计费账户。

## 遇到问题

- 邮箱已被使用：返回登录，使用该邮箱登录或绑定已有账号。
- 验证码、注册链接或认证入口过期：从登录页重新发起，不要反复创建账号。
- 审核或开通长时间没有进展：通过工单或官方支持渠道提供脱敏邮箱、申请标识和发生时间。

> 账号仅限本人使用。不要向他人提供密码、邮箱验证码、多因素认证信息或 SSH 私钥；不要在公开群聊中发送证件照片。
