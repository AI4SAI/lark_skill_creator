# 存储空间

## 数据放在哪里

个人脚本、输入和结果放在 Home。组内软件、公共数据放在组织共享目录，课题数据放在对应项目目录。配额跟着目录走，查空间时进入实际存放数据的位置。

在 SAI 主站，Home 与组织目录使用 Lustre。`/tmp`、`$CACHE_LOCAL` 等节点本地空间用于中间文件，需要保留的结果请在任务结束前写回工作目录。

### 查看当前目录的配额

``` bash
pwd
sai storage local-quota . --format table
```

日常可直接用 `quota` 查当前目录，用 `quota "$HOME"` 查 Home。脚本或 Agent 使用上面的 `sai storage local-quota`，无需先登录控制台。

共用组织额度的目录查 `quota` 时，显示的是所有共用目录的合计用量和配额。当前子目录占用多少，可用下面的 `ncdu` 查看。

同时看空间用量和文件数（inode）：很多小文件也会用完配额。开通超额后，包含额度与写入硬上限可能不同。超过软限额时，`Grace=notify` 只提醒，普通宽限期到期会限制新增写入。达到硬上限也会限制写入。

如果提示“未分配配额”，先确认查询的是自己的工作目录，而不是 `/home` 或 `/org` 根目录。仍查不到时，把目录和报错交给管理员。

### 空间不足时

先用下面的 `ncdu` 找到大文件，清理已不需要且没有任务正在使用的数据。需要扩容时，在控制台查看该目录的存储额度或联系管理员。

重要结果请另留备份。透明压缩能节省后端空间，自己的可写额度仍看 `quota`。

## 统计存储空间占用 `ncdu`

用 `ncdu -r .` 扫描当前目录并按占用排序。`-r` 以只读方式浏览。目录中文件很多时扫描会较慢，尽量从需要排查的子目录开始。

用方向键进入目录，按 `q` 退出，按 `a` 切换文件逻辑大小与磁盘占用显示。`ncdu` 帮你找谁占空间，`quota` 告诉你还能写多少。

## 💡FAQ

#### Q: 容量还没用满，为什么提示 quota exceeded？

> **A：**还可能是文件数额度用满了。查看当前目录的容量和文件数两项配额，再用 ncdu 找占用较多的子目录。

#### Q: 组织总额度还有剩余，为什么某个目录写不进去？

> **A：**这个目录可能分到了单独额度。给目录留出的份额和大家共用的份额分别计算，管理员可以在控制台调整，并查看站点生效状态。

#### Q: 把文件存到计算节点本地缓存，任务结束后会自动保存吗？

> **A：**重要结果要主动写回持久存储。节点本地缓存适合中间文件，换节点可能读不到，也可能被清理。

#### Q: 已经获得共享权限，为什么有些文件仍打不开？

> **A：**目录的协作授权和文件自身权限都会影响访问。程序可能创建仅本人可读的文件，移入、复制或解压也可能保留原权限。请先确认站点授权已生效，再由文件所有者检查这些文件的权限。按默认设置新建的文件仍无法共享时，请反馈给管理员检查默认协作设置。

#### Q: 用硬链接分享文件，撤销原目录权限就能收回吗？

> **A：**硬链接指向同一份数据，在任一路径修改都会影响另一处。对方若能通过另一个共享目录访问它，撤销原目录授权后仍可能访问。创建硬链接前，请检查两边的共享范围和文件权限。

#### Q: 文件有写权限，为什么编辑器仍保存失败？

> **A：**有些编辑器先新建临时文件，再替换原文件，因此也需要所在目录的写权限。多人共同编辑时，把文件放到已授予编辑权限的共享文件夹或项目目录。让 Agent 排查时，提供保存失败的路径和报错，核对文件与所在目录两处权限。
