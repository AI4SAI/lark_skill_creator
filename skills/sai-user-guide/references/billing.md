# 费用与服务

先认准谁在使用、哪个计算账户承担费用、钱由谁支付。个人使用、组织统一付款、课题归集和独立项目预算有不同的管理方式，见[团队协作](collaboration.md)。

**服务等级** 决定可以使用的资源规模和队列条件；**预算** 限制可以花多少；**钱包与 SAI Credit** 是不同的资金或额度记录。等级高不等于余额充足，有余额也不等于拥有某个项目的使用权。

充值、订阅和合同怎么选，要结合当前商品、使用节奏、适用对象和已有合同。现金、赠送额度和套餐额度的用途、有效期与退款条件分别查看，不承诺自动叠加优惠，也不把历史卡时迁移规则当成新充值政策。

费用问题按实际账单解释：运行中的金额可能是估算，结算记录才是最终扣费依据。算力、存储和 Pilot 模型用量分别核对对应的服务与账单；不要因为某项曾经免费，就推断现在仍免费。

申请发票、退款或处理支付异常，使用控制台当前提供的订单、财务和工单入口。查不到最终结果时保留订单与操作状态，不把“请求已收到”说成钱已到账或退款完成。

论文致谢、推荐或其他激励，只引用当前正式公开的政策和明确约定。不从旧教程、内部讨论稿或论坛建议中许诺奖励金额。原文入口：[账号、计费与资金](https://vcnn7siwx4yx.feishu.cn/wiki/LJo9wzMv7ipb5ckeKfEceDEPn4d)。
