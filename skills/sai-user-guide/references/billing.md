# 费用与服务

先认准谁在使用、哪个计算账户承担费用、钱由谁支付。个人使用、组织统一付款、课题归集和独立项目预算有不同的管理方式，见[团队协作](collaboration.md)。

**服务等级** 决定可以使用的资源规模和队列条件；**预算** 限制可以花多少；**钱包与 SAI Credit** 是不同的资金或额度记录。等级高不等于余额充足，有余额也不等于拥有某个项目的使用权。

怎么买，先看需求：

| 需求 | 购买方式 |
| --- | --- |
| 用量不固定 | 按量使用，按任务分配的资源和占用时间计费 |
| 持续计算，算力和存储都需要 | 随心算，按 30 天购买计算额度、存储和算力等级。当期额度到期失效，用完后继续按量计费 |
| 有采购预算，或套餐不合适 | 合同模式，计算单价、并行算力、存储、席位和项目名额分别约定 |

合同可以按需要组合。例如课题组只想提高并行算力、现有存储够用，可以单独约定算力等级和计算单价。等级决定可同时使用的资源上限，单价决定实际消费费用。需要固定时段独占整节点，可约定专属资源，整段预订时间都计费。

合同补充部分服务时，同一对象可以继续订阅随心算。合同统一提供该对象算力时，随心算的新购、续费和升级会关闭，已付权益保留至到期。组织与独立项目分别约定，课题项目共用组织的服务约定。

有效 Credit 先抵扣适用的公开计算费，剩余用量按合同现金价结算。例如公开价 100 元、Credit 抵 40 元，剩余部分按合同八折，现金支付 60 × 0.8 = 48 元。存储、订阅和专属资源按各自订单结算。

按量和随心算在[控制台](https://www.open-sai.com/portal/)办理。合同采购可通过[购买说明中的团队邮箱或用户交流群](handbook/de0cae9d9928cde1be3cc6b6/index.md)联系运营，说明预算、资源和使用期限。充值形成现金余额，具体权益由订单或合同确定。完整选择说明和购买 QA 见[账号、计费与资金](handbook/de0cae9d9928cde1be3cc6b6/index.md)。

费用问题按实际账单解释：运行中的金额可能是估算，结算记录才是最终扣费依据。算力、存储和 Pilot 模型用量分别核对对应的服务与账单；不要因为某项曾经免费，就推断现在仍免费。

**Q: 页面上的运行中费用没变化，就说明没有继续计费吗？**

运行中的金额是估算，页面刷新和结算可能晚于实际资源占用。先确认任务是否已结束、资源是否释放，再核对消费流水。暂停（suspend）仍保留资源，暂停期间正常计费，见[计算任务](compute.md)。

**Q: CPU-only 任务免费吗？**

按所申请资源和占用时间计费，CPU 和内存的申请量都可能影响费用。提交前查看控制台价格和资源要求。

费用突然大幅变化或与事先说明不一致时，保留任务编号、时间和页面记录，提交费用核查。申请发票、退款或处理支付异常，使用控制台当前提供的订单、财务和工单入口。查不到最终结果时保留订单与操作状态，不把“请求已收到”说成钱已到账或退款完成。
