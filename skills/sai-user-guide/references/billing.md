# 费用与服务

先认准谁在使用、哪个计算账户承担费用、钱由谁支付。个人使用、组织统一付款、课题归集和独立项目预算有不同的管理方式，见[团队协作](collaboration.md)。

**服务等级** 决定资源规模和队列条件。**预算** 控制支出。**钱包与 SAI Credit** 分别记录资金和抵扣额度。计算前分别确认可用资源、可用资金和项目使用权限。

怎么买，先看需求：

| 需求 | 购买方式 |
| --- | --- |
| 用量不固定 | 按量使用，按任务分配的资源、累计运行时长和适用单价计费 |
| 每月稳定计算，也需要存储和并行能力 | 随心算，按 30 天购买计算额度、存储和算力等级。当期额度到期失效，用量稳定时更划算 |
| 有采购预算，或套餐不合适 | 合同模式，计算价、随心算、包机、存储、席位和项目名额按需组合 |
| 固定时段独占整节点 | 包机，按节点和整个预订时段付费，空闲也计费 |
| 增加可存放的数据量 | 存储，按容量和周期以人民币购买，计算 Credit 不抵存储费 |

随心算的优惠是套餐价格换来计算额度、存储和等级。任务按公开价消耗当期额度，未用完的额度到期失效。用量少时，按量可能更合适。额度用完后，后续计算按公开按量价结算。

合同可以按需要组合。等级决定可同时使用的资源上限，单价决定实际消费费用，资源范围、使用期限、用量或金额和付款方式一起谈清。合同可采用随心算，也可为不同对象或服务分别采购。组织与独立项目分别约定，课题项目共用组织的服务。合同专用款只承担合同内消费，例如只买 V100 卡时，CPU、A100 和存储须另行计费、另行支付。

同一计算消费，随心算与合同固定价二选一，通用红包仍属于优惠，不能额外叠加。充值到账不自动附送优惠，大额、年度和组团采购统一在报价中约定。已享受充值赠送的采购，先用完原方案对应的余额，再办理随心算或包机。切换前由运营核对原充值、赠额和已用情况。

Credit 按来源、用途和期限使用。已批准权益按原约定履行，补偿、纠错返还、历史赠送和误叠优惠分别核对原记录，确认处理方案。Agent 代购或兑换前，应核对适用计价方案和已有充值赠送余额，页面可下单不构成额外优惠批准。

包机按整段报价结算，空闲或提前结束自己的任务不减价。订单覆盖内的作业不重复收节点费，其他共享队列任务照常结算。计算 Credit、随心算或普通作业合同折扣不叠包机价，存储和软件许可证另行购买。标准规格可自助订购，特殊需求另行报价。

符合用途和期限的 Credit 也可抵扣平台 AI 服务。模型专用额度只用于明细标注的 AI 服务，原现金欠款按账单保留。实际可用额还计入欠款、未结费用和预留。

随心算当期升级按原订单剩余价值抵扣，新档重新计 30 天，预付未来周期一并升级。计算部分取剩余时间比例与剩余额度比例的较小值，存储部分按剩余时间折算，另购存储沿原周期。具体看升级报价。

按量和随心算在[控制台](https://www.open-sai.com/portal/)办理。合同采购可通过[购买说明中的团队邮箱或用户交流群](handbook/de0cae9d9928cde1be3cc6b6/index.md)联系运营，说明预算、资源和使用期限。充值形成现金余额，具体权益由订单或合同确定。完整选择说明和购买 QA 见[账号、计费与资金](handbook/de0cae9d9928cde1be3cc6b6/index.md)。

运行中的金额可能是估算，最终扣费查看结算记录。算力、存储和 Pilot 模型用量分别核对对应服务的价格和账单。

**Q: 页面上的运行中费用没变化，就说明没有继续计费吗？**

SAI 主站普通按量作业的预估和结算都按 Slurm 记录的累计运行时长计算。暂停期间不累计，任务进入 CG/COMPLETING（正在结束）或已结束后停止累计。消费流水可能稍后入账，已结账单保留原记录。具体见[计算任务](compute.md)。

**Q: CPU-only 任务免费吗？**

按所申请资源和占用时间计费，CPU 和内存的申请量都可能影响费用。提交前查看控制台价格和资源要求。

费用突然大幅变化或与事先说明不一致时，保留任务编号、时间和页面记录，通过[问题反馈](handbook/c62336b8dd845c2de07d2bf9/index.md)提交费用核查。申请发票、退款或处理支付异常，使用控制台的订单和财务入口。到账和退款进度从原订单查询，结果未明时保留订单与操作记录。

支付宝自助开票按每笔净实收整笔办理。开票处理中或已开票会锁定自助退款，计划退回未用款时先退款再开票。依法或依合同退款由财务核定。
