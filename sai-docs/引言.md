# 👓SAI超级计算机简介

赛先生（SAI）超级计算机是由ENTROPY-YU独立设计与开发的面向科学计算与AI for Science的<text color="red" bgcolor="light-yellow">**开源超级计算机**</text>，简称“SAI”。

## SAI的“开源”

技术栈完全基于<text bgcolor="light-yellow">开源知识</text>构建，文档分布在广大<text bgcolor="light-yellow">开源社区</text>，运行的主要软件为<text bgcolor="light-yellow">开源软件</text>

## SAI的使命

- 让超大规模GPU加速并行计算和机器学习方法普惠每一位科学计算用户
- 让每位研究者都能<text color="red" bgcolor="light-yellow">**轻松地启动千卡并行**</text>，以此研究<text bgcolor="light-yellow">真实物理体系</text>，解决人类社会面临的<text bgcolor="light-yellow">重大科学难题</text>

## SAI的能力

SAI采用自主设计的“千卡<text bgcolor="light-yellow">超节点</text>”GPU集群，启动千卡并行易如反掌，可轻松且高效地实现以下计算：

- 万原子级 VASP 第一性原理分子动力学模拟
- 数万原子级 ABACUS 第一性原理分子动力学模拟
- 10万原子以上 CP2K 第一性原理分子动力学模拟
- 1~10亿原子纳秒级 / 百万~千万原子微秒级 DeePMD 分子动力学模拟
- 力争实现百亿原子级 NEP (GPUMD) 分子动力学模拟 (通过开源社区合作)
- ……

# 🏆SAI有什么优势？

<callout emoji="balloon" background-color="light-orange" border-color="light-orange">

0️⃣采用原生<text bgcolor="light-yellow">Slurm调度系统</text>，所有基础环境已预配置、<text bgcolor="light-yellow">开箱即用</text>，用户登录即可<text bgcolor="light-yellow">直接使用模板</text>提交任务，<text color="red" bgcolor="light-yellow">**任务开始运行后才计费**</text>，区别于市场上一些需要用户自行配置环境且调试代码和处理任务输入/输出文件过程照常计费（开机即计费）的方案

1️⃣采用先进的计算组网（Fabric）架构，优选改良了核心硬件，优化了硬件BIOS、OS内核、并行计算通信库和任务调度策略，提供具体场景的[性能调优教程和模板](https%3A%2F%2Fvcnn7siwx4yx.feishu.cn%2Fwiki%2FNVfBwF7d2ijPPykuq6ScDb3RnVi)，显著提高计算效率和资源利用率——SAI的<text color="red" bgcolor="light-yellow">**改进型V100-SXM2**</text>在许多典型计算用例中性能达到市面主流V100的近2倍，<text color="red" bgcolor="light-yellow">**与A100-SXM4持平**</text>

2️⃣采用成熟、主流的超级计算机硬件生态（<text bgcolor="light-yellow">x86＋CUDA＋IB</text>体系，区别于一些采用不成熟硬件的超算）和新版本的底层软件系统（<text color="red" bgcolor="light-yellow">**Ubuntu 24.04**</text>、Slurm 25.04等，区别于一些采用CentOS7等极老软件系统的超算），整套超级计算机系统的<text bgcolor="light-yellow">通用性和易用性</text>达到领先水平

3️⃣采用统一的设计规范和部署标准，支持用户<text bgcolor="light-yellow">本地</text><text bgcolor="light-yellow">集群与</text><text bgcolor="light-yellow">SAI</text><text bgcolor="light-yellow">深度融合</text>，以便用户在本地和云端算力之间迅速切换、按需调用

4️⃣具有灵活的可扩展性与可维护性，可根据客户需求和市场发展<text bgcolor="light-yellow">持续开发并升级</text>整套系统任一组件，确保系统始终处于行业领先水平

5️⃣开发与运营团队包含逾20名<text bgcolor="light-yellow">科学研究一线人员</text>，深刻理解真实科研场景中的<text bgcolor="light-yellow">关键科学问题</text>，能够及时导入新研发的科学计算应用栈，并与广大客户<text bgcolor="light-yellow">密切沟通</text>

6️⃣始终以解决科学问题为导向，重点支持高水平科研，研究人员在论文中<text bgcolor="light-yellow">致谢SAI即可获得丰厚奖励</text>
