# 普通用户 Skill 的维护

对外只有 `sai-user-guide` 一个入口。用户表达要做什么，入口再指向对应参考；不要按平台介绍、使用手册和 CLI 拆成三个重复触发的 Skill。

## 同步方式

采用现有 Git 仓库统一分发：飞书编辑手册 → 原有导出器生成候选 → PR 审阅 → 同一个 tag 供各端读取。维护者更新一次，机器侧拉取和构建沿用各产品的部署流程，不需要新服务或后台 Agent。

| 使用方 | 读取位置 | 更新方式 |
| --- | --- | --- |
| 客服 bot | 同一 Skill 的 `references/` | 原 `PublicKnowledge` 读取正文和 `manifest.json`，同时覆盖十份场景参考；拉取版本后重载原知识插件 |
| Pilot | 完整的 `sai-user-guide/` | 原生 Skill provider 加载固定版本，沿用已有运行时发布流程 |
| 用户客户端 | 完整的 `sai-user-guide/` | 原生安装器按 tag／提交号更新，已有打包工具保留个人改动和备份 |

`references/handbook/` 是飞书原文的生成副本，正文、图片、附件和同步块一起导入；编辑回到飞书。其余场景参考在 Git 维护。客服索引由相同文件重建，不再人工维护另一份正文。主入口只载入短说明，原文按需读取，整本手册不进入每轮上下文。

手册更新时，在同一 PR 中检查相关简短参考是否需要同步修改。发布使用既有 Git 版本和 Skill 文件清单；消费者记录实际加载的提交号。断网客户端保留上次安装的版本，更新在重新安装／加载后生效。公开资料撤回后，新版本移除对应文件；已经分发到用户设备的副本无法远程收回。

首次接入时，客服将原知识目录指向上述子目录，Pilot 将通用手册指引切换到统一 Skill。Pilot 特有的工具 schema、授权与提交流程仍由产品实现维护。当前 Pilot 仓库另存的通用 `sai-hpc` 指引应在这一步迁移，避免两个入口继续回答同一类产品规则。接入验收使用实际检索／原生 Skill 加载；仅构建成功不代表线上已更新。

| 用户能力 | 资料 | 更新来源 |
| --- | --- | --- |
| 平台选择、多站点、专家终端、集群合作 | `platform.md` | 官网和实际服务入口 |
| 账号、默认工作身份、站点开通、SSH、公钥、文件挂载 | `access.md` | 当前账号中心、连接指引和用户手册 |
| 组织、共享文件夹、课题／独立项目、外部协作 | `collaboration.md` | 已确认的团队协作规则和控制台行为 |
| 额度池、目录分额、Home 资助、文件数、传输与缓存 | `storage.md` | 当前存储产品与用户手册 |
| Slurm 账户推定、原生调度、资源选择、数组任务、排队、调整与取消 | `compute.md` | CLI 仓库的 `docs/job-submit-policy.md`／`site/slurm/job_submit.lua`、当前站点及任务回执 |
| 科研软件、环境、模板、GPU／MPI／I/O 调优 | `software.md` | 软件与性能手册、站点实际环境 |
| Pilot 文件／代码／终端、Agent 协作、计算和历史 | `pilot.md` | 当前工作台能力与已开放的产品入口 |
| BBS 检索、问答、采纳、作者确认、原任务续办 | `community.md` | BBS 当前界面、权限与真实回执 |
| 付款归属、套餐／合同、Credit、账单、发票和激励 | `billing.md` | 当前商品、本人合同及正式公开政策 |
| CLI／MCP 发现、安装、授权、执行与读回 | `tools.md` | 已安装 CLI 的 `skill`／`describe` 及宿主工具说明 |

参考只放能帮助 Agent 作判断的简短说明。教程中的原例子、图片和视频通过原文入口阅读；没有针对具体内容的授权，不改写或重新发布它们。未来收录已经授权的原文时，使用原有导出、审核和哈希链，保留作者表达与素材；公开包只收经过明确公开审核的文件。

面向用户的解释先写规则和具体例子，沿用作者已经确认的表述。脚本、环境变量、符号链接等细节放在按需技术参考中，让主解释保持简短。

易造成费用、资源或分享误解的规则沿用手册已有的 QA。各页引用 FAQ 汇总里的同步块时，更新同步源；其他页的问答由汇总链接过去。Skill 保留暂停计费等关键短答，并指向同一原文。保持原问题、教学媒体和章节次序。

产品变动时，先找到受影响的行和对应参考，再给出内容差异。不要把开发方案、未启用的开关或内部销售讨论写成现行承诺。界面存在、工具可调用、操作已接受和最终生效分别核实，尤其是 Pilot 计算、BBS 审核及站点权限。

当前金额、余额、资源与资格由工具或正式页面读取。版本清单用于识别安装内容，不把快照日期包装成业务事实永远有效；公共包不带私有来源路径、原始审计记录、凭据或内部运维 Skill。

发版前运行完整测试、检查链接和隐私范围，并用新安装包完成代表性用户任务。安装验证需要覆盖首次安装、旧包迁移、个人改动保护、备份可恢复和失败回滚。更新不会改写已经进入旧对话的内容，验收应在新加载该版本的会话中进行。

工具代码、人工手册与第三方参考各自保留原有权利和来源；此包不为链接指向的原文重新授予许可。仓库中的 `slurm_docs` 是独立历史快照，不随普通用户 Skill 打包，也不作为当前站点规则。
